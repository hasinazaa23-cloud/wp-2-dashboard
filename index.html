INTEGRASI IOT

Hubungkan perangkat

Masukkan endpoint REST yang mengembalikan data sensor dalam format JSON. Dashboard akan membaca data setiap 5 detik.

Format data yang didukung{"fillPct":72,"gasIndex":34,"temperatureC":29.4,"humidityPct":68,"distanceCm":28}Alternatif volume: distanceCm + binHeightCm. Alternatif gas: mq135Raw (rentang ADC 0–1023). Lokasi opsional: latitude dan longitude.

API harus dapat diakses publik dan mengizinkan CORS dari domain website. Jangan masukkan token rahasia di website publik.
